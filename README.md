# PGG Caddie

The PGG Caddie runs on a league host's golf PC. It drives GSPro from an iPad, runs PGG matches, and puts the league's scoring overlays on the projector, in the league's own colors and logo.

## Download

**[Download PGGCaddieSetup.exe](https://github.com/platodw/pgg-caddie-releases/releases/latest/download/PGGCaddieSetup.exe)** (Windows 10 or 11)

The full walkthrough is on pggtour.com in your league's Admin, Caddie tab.

## Install

1. Run `PGGCaddieSetup.exe` on the golf PC (the one running GSPro). No admin rights needed.
2. Windows may say it "protected your PC" because the installer isn't signed. Click **More info**, then **Run anyway**.
3. When the Caddie first starts, Windows Firewall asks whether to allow it. Allow it on **private networks**, so the iPad can reach it.
4. A page opens with a QR code. Scan it with the iPad, then add the page to the iPad's Home Screen.
5. Pair the Caddie with your league using the code from Admin, Caddie on pggtour.com.

The Caddie lives in the system tray, next to the clock, and updates itself from this page (Settings on the iPad).

This repository only hosts the installer. Questions go to your league's commissioner or the PGG Tour.
